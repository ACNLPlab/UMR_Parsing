Generate UMR graphs using our best model by opening the BiBL directory and using bibl_inf.sh

First, download the checkpoint from the link below and move it to BiBL/best_ckpt.

Then, create a conda env using BiBl/bibl_env.yml.

Next, create a test file in the format found in test.txt.

Finally, run sbatch bibl_inf.sh to genreate UMR graphs.
